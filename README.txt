BEAUTY INDEX — 뉴스페이퍼형 K-뷰티 데이터 홈페이지

실행 방법
1. 압축을 풉니다.
2. index.html을 브라우저에서 엽니다.

폴더 구조
- index.html
- assets/css/style.css
- assets/js/main.js
- assets/img/

주요 기능
- 반응형 뉴스페이퍼/에디토리얼 레이아웃
- K-뷰티 수출 지표 및 트렌드 그래프
- 기사, 데이터 카드, 루틴 클릭 시 상세 팝업
- ESC 및 배경 클릭으로 팝업 닫기
- 모바일 메뉴와 스크롤 애니메이션
- 뉴스레터 이메일 입력 검증

참고
화면의 수치와 문구는 요청하신 두 레퍼런스 사이트의 콘텐츠를 데모용으로 편집해 반영했습니다.
